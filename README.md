# Abartılı Yavaş Selam Veren Program

Bu program, insanlığın en büyük sorununa çözüm bulmak için tasarlanmıştır: **acelecilik**.

## Neden Var?

Modern dünyada her şey hızlı. E-postalar anında, mesajlar saniyede, hatta kahve bile beklenmeden içiliyor. Bu program, size **zamanın tadını** çıkartmayı öğretir. Her harf, bir meditasyon seansıdır. Her saniye, bir felsefe dersidir.

## Nasıl Çalışır?

```bash
python selam.py
```

Program "Merhaba, evren!" yazısını harf harf, ağır ağır yazar. Araya rastgele varoluşsal yorumlar sıkıştırır. Beklemek zorundasınız. Kaçış yok.

## Özellikler

- Gerçekten çalışır (inanılmaz ama doğru)
- Hiçbir işe yaramaz
- Sizi düşünmeye zorlar
- CPU'nuzu neredeyse hiç yormaz (sadece zamanınızı yer)
- Felsefi derinlik: 11/10

## Uyarı

Bu programı çalıştırmadan önce en az 5 dakika boş vaktiniz olduğundan emin olun. Aksi takdirde varoluşsal kriz yaşayabilirsiniz.
